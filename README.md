# detectability-HFC-breaches-1D-model
Model code and input data for Bayesian 1-box HFC model. Input data includes HFC consumption data, Kigali Amemdment phasedown schedules, and AGAGE global mean mole fractions for HFC-134a, HFC-143a, HFC-125 and HFC-32. Model code includes pre-processing, Bayesian inference step, future projections, and breach detection analysis.
